# PZ09: регистрация и вход

Отдельный Go-модуль с PostgreSQL, GORM, chi и bcrypt. `POST /auth/register` создаёт пользователя и возвращает 201; повторный email — 409. `POST /auth/login` возвращает 200 при верном пароле и одинаковый 401 для неверного пароля и неизвестного email. Пароли и их хэши не входят в JSON-ответы и логи. Токен здесь не выдаётся: он относится к PZ10.

## Запуск и автоматическая проверка на Windows

Из любого каталога PowerShell:

```powershell
& 'D:\MAG\GO\practic\practices\pz09-auth\run-local.ps1'
```

Нужен запущенный PostgreSQL на `127.0.0.1:5432`, роль `postgres` с правом создать учебную базу и `psql.exe`. Сценарий запрашивает пароль скрытым вводом один раз, создаёт отсутствующую базу `pz9_auth`, запускает сервер на свободном loopback-порту и проверяет 201/409/200/401, одинаковость ошибок входа, наличие таблицы и bcrypt-хэша. Повторный запуск использует существующую базу, а для пользователя берёт новый случайный email. Сценарий завершает свой сервер и восстанавливает переменные окружения. Для другой роли или порта можно заранее задать `PGUSER` и `PGPORT`.

## Ручной запуск

После настройки PostgreSQL и создания базы:

```powershell
& 'D:\MAG\GO\practic\setup.ps1'
Set-Location 'D:\MAG\GO\practic\practices\pz09-auth'
$env:DB_DSN = 'postgres://USER:PASSWORD@127.0.0.1:5432/pz9_auth?sslmode=disable'
$env:BCRYPT_COST = '12'
$env:APP_ADDR = '127.0.0.1:18089'
go run ./cmd/api
```

Строка выше — только шаблон; реальные учётные данные не сохраняйте в файлах или командной истории. Для обычного локального запуска используйте `run-local.ps1`. `BCRYPT_COST` по умолчанию 12, `APP_ADDR` — `:8080`. В учебных HTTP-запросах используйте тестовые пароли, а не личные. Для публичного развёртывания потребуются HTTPS и ограничение частоты входа.

Структура: `cmd/api/main.go` — маршруты и старт; `internal/core/user.go` — модель; `internal/repo/user_repo.go` — GORM, миграция и поиск; `internal/http/handlers/auth.go` — валидация, bcrypt и ответы; `internal/platform/config/config.go` — конфигурация. Тесты находятся рядом с обработчиками.
