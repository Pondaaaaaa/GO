# Работа с практиками Go

- Репозиторий содержит отдельные практики в `practices/` и отчёты в `reports/`. Выполняй только номер, названный в текущем запросе. Для каждой новой практики готовь отчёт в Markdown и Word (`reports/word/pzNN.docx`).
- Краткий указатель находится в `context/INDEX.md`. Читай только страницу нужной практики и `context/REPORTS.md`; исходный DOCX по указанному там пути открывай при неоднозначности или для сверки требований.
- Для работы в PowerShell сначала выполни локальный `setup.ps1` в корне репозитория. Он не публикуется. Каждая практика — отдельный модуль Go.
- Если практика требует локальную БД или другой сервис, читай `context/AUTOMATION.md`: подготовь один воспроизводимый PowerShell-скрипт для настройки, запуска и проверки. Пользователь должен вводить только пароль PostgreSQL, когда он действительно нужен.
- Проверяй фактический результат командами из задания. В отчёт заноси только реально полученные ответы, версии и результаты тестов. Не создавай вымышленные скриншоты и измерения.
- Репозиторий публичный. Не добавляй пароли, токены, `.env`, реальные строки подключения, исходные DOCX или локальный SDK Go. Перед коммитом проверь список файлов и diff.
- После завершения практики проверь её код и отчёт, затем подготовь отдельный локальный коммит. Push и pull request делает пользователь; не выполняй их без нового прямого поручения.
