# Практические занятия по Go

Один публичный репозиторий для 16 отдельных практик. Код каждой работы будет находиться в `practices/pzNN-*`, отчёт — в `reports/pzNN.md`, реальные скриншоты — в `reports/images/pzNN/`.

Рабочие задания DOCX хранятся локально в `D:\MAG\GO\Текущий контроль` и в репозиторий не копируются. Краткие требования и промпты для Codex находятся в `context/` и `prompts/`.

Go установлен локально на этом компьютере. Для нового окна PowerShell выполните `& 'D:\MAG\GO\practic\setup.ps1'`. Затем проверьте `go version`. Файл `setup.ps1` зависит от локального пути и не отправляется в GitHub.
