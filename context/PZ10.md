# Практика №10 — JWT и права доступа

Источник: `D:\MAG\GO\Текущий контроль\Практическое занятие №10.docx`.

Отдельный Go-модуль `practices/pz10-auth/`, chi, bcrypt, HS256 JWT. Пользователи admin/user могут храниться в памяти с bcrypt-хэшами. `JWT_SECRET` обязателен; access TTL 15 минут, refresh TTL 7 дней. Публичный `POST /api/v1/login` выдаёт оба токена; `POST /api/v1/refresh` принимает refresh, отзывает старый refresh в памяти до `exp` и выдаёт новую пару. AuthN извлекает Bearer, проверяет подпись/срок/тип и кладёт claims в context; AuthZ даёт 403 при нехватке роли. `GET /api/v1/me` доступен user/admin; `GET /api/v1/admin/stats` только admin; `GET /api/v1/users/{id}` для user только при `id == sub` (admin может читать любой профиль).

Отчёт: титульная часть с пустыми ФИО/группой, описание, дерево, запуск, реальные выводы login, me/admin, 403, refresh со старыми/новыми access, команды curl/PowerShell, ответы на пять контрольных вопросов. Форматы Markdown и Word. Скриншоты или настоящие вставки вывода; не печатать токены/секреты в публичном отчёте. Задания со звёздочкой (RS256/ротация, rate limit) отделить от обязательной части; единый JSON ошибок и логирование можно реализовать при наличии времени.
