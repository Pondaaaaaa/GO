# Практика №11 — REST API заметок

Источник: `D:\MAG\GO\Текущий контроль\Практическое занятие №11.docx`.

Отдельный Go-модуль с chi и архитектурой handler → service → in-memory repository. Сущность Note: ID, Title, Content, CreatedAt, UpdatedAt. Маршруты `GET/POST /api/v1/notes` и `GET/PATCH/DELETE /api/v1/notes/{id}`. Коды 200/201/204/400/404/500 и JSON-ответы; 204 без тела. Каталоги `cmd/api`, `internal/http`, `internal/core`, `internal/repo`, `api/openapi.yaml`. Запуск `go run ./cmd/api`, проверка через curl. Порт 8080 по примеру, но для локальной проверки выбрать свободный через `PORT`.

Отчёт: цель, теория REST/CRUD, дерево проекта, примеры `main.go`, репозитория и обработчиков, реальные ответы API и настоящие скриншоты curl или Postman, выводы и ответы на семь контрольных вопросов. Markdown и Word по `context/REPORTS.md`.
